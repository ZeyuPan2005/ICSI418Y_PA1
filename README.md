## The name of my application: 
Task List

## Description
The application allows users to enter a task, select its priority, and add it to the task list. 
Users can also mark a task as completed or delete a task from the list.

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open index.html.
4. The task list application will run directly in the browser.

## Known Limitations
1. The browser's validation message for an empty task may appear in Chinese depending on the browser language settings.
